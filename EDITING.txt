Редагування портфоліо

index.html — тексти головної сторінки, освіта, контакти та обкладинки робіт.
script.js — назви, описи і списки фотографій кожного проєкту в об’єкті projects.
styles.css — кольори, шрифти, адаптивність та ефекти наведення; змінні на початку файлу змінюють їх для всього сайту.
assets/ — фото; assets/m/ — легші копії для телефонів; assets/thumbs/ — мініатюри для галерей. Нове фото: python3 tools/images.py оригінал.jpg назва.

Щоб змінити порядок фотографій, перестав відповідні рядки в images потрібного проєкту. Перший елемент — перше фото у галереї. Обкладинка на головній сторінці задається окремо в index.html.

На GitHub можна відкрити файл, натиснути олівець, внести зміни та зберегти через Commit changes. Зміни в гілці main з’являються на сайті https://anastasia-art-don.github.io/portfolio/ приблизно за хвилину.

Локальний перегляд: npm start або node server.cjs, адреса http://127.0.0.1:4174.
