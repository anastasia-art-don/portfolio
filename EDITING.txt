Редагування портфоліо

index.html — тексти головної сторінки, освіта, контакти та обкладинки робіт.
script.js — назви, описи і списки фотографій кожного проєкту в об’єкті projects.
styles.css — кольори, шрифти, адаптивність та ефекти наведення.
assets/ — зображення; assets/thumbs/ — мініатюри для галерей.

Щоб змінити порядок фотографій, перестав відповідні рядки в images потрібного проєкту. Перший елемент — перше фото у галереї. Обкладинка на головній сторінці задається окремо в index.html.

На GitHub можна відкрити файл, натиснути олівець, внести зміни та зберегти через Commit changes. Після підключення GitHub Pages зміни в опублікованій гілці потраплятимуть на сайт.

Локальний перегляд: npm start або node server.cjs, адреса http://127.0.0.1:4174.
