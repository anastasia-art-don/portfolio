# Портфоліо Анастасії Степаненко

Сайт на HTML, CSS і JavaScript. Збірка та сторонні залежності не потрібні.

## Локальний запуск

Потрібен Node.js. У папці проєкту виконайте:

```sh
npm start
```

Відкрийте http://127.0.0.1:4174.

## Де редагувати

- `index.html` — тексти, освіта, контакти та обкладинки робіт.
- `styles.css` — оформлення, адаптивність, анімації та ефекти наведення. Шрифти, кольори, ширина сторінки й швидкість анімацій задаються змінними на початку файлу.
- `script.js` — об’єкт `projects` із назвами, описами й порядком фотографій; логіка галерей.
- `assets/` — фото для великих екранів, до 2400 px по довшій стороні.
- `assets/m/` — легші копії для телефонів, до 1400 px.
- `assets/thumbs/` — мініатюри галерей, 200×160 px.
- `tools/images.py` — готує фото з оригіналу в усіх трьох розмірах.
- `assets/video/` — анімації в MP4. У списку `images` відео записується з третім елементом `"video"`, а його перший кадр лежить поруч як звичайне фото з тією самою назвою.
- `EDITING.txt` — додаткова інструкція з редагування.

Файли зображень у списках `images` вказуються без розширення `.webp`. Нове фото додається командою `python3 tools/images.py шлях/до/оригіналу.jpg назва`: вона створює `assets/назва.webp`, копію для телефона й мініатюру (потрібен Pillow: `pip install pillow`). Якщо копії чи мініатюри немає, сайт показує повне фото, тож нічого не ламається. Обкладинка на головній задається окремо в `index.html`.

## Передача та публікація

Код і всі зображення сайту знаходяться у цьому репозиторії. Повні оригінали фото, PDF, AI та відео доступні в [Releases](https://github.com/anastasia-art-don/portfolio/releases/tag/portfolio-handoff-2026-10-22). У релізі завантажте `download_and_restore.py` і запустіть `python download_and_restore.py`. Скрипт завантажить частини архівів, перевірить SHA-256 і розпакує всі матеріали в папку `originals/`. Це окремі матеріали для майбутньої роботи; для запуску сайту вони не потрібні.

Сайт опублікований через GitHub Pages: https://anastasia-art-don.github.io/portfolio/. Кожен коміт у гілку `main` з’являється на сайті приблизно за хвилину.

Анімації враховують системне налаштування зменшеного руху. Галереї підтримують стрілки, клавіатуру та свайпи на сенсорному екрані.
