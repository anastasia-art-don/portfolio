# Портфоліо Анастасії Степаненко

Сайт на HTML, CSS і JavaScript. Збірка та сторонні залежності не потрібні.

## Локальний запуск

Потрібен Node.js. У папці проєкту виконайте:

```sh
npm start
```

Відкрийте http://127.0.0.1:4174.

## Де редагувати

- `index.html` — тексти, освіта, контакти та обкладинки робіт.
- `styles.css` — оформлення, адаптивність, анімації та ефекти наведення.
- `script.js` — об’єкт `projects` із назвами, описами й порядком фотографій; логіка галерей.
- `assets/` — зображення для сайту.
- `assets/thumbs/` — відповідні мініатюри галерей.
- `EDITING.txt` — додаткова інструкція з редагування.

Файли зображень у списках `images` вказуються без розширення `.webp`. Для кожного кадру галереї потрібні основний файл у `assets/` та мініатюра з такою самою назвою у `assets/thumbs/`. Обкладинка на головній задається окремо в `index.html`.

## Передача та публікація

Код і всі зображення сайту знаходяться у цьому репозиторії. Повні оригінали фото, PDF, AI та відео доступні в [Releases](https://github.com/anastasia-art-don/portfolio/releases/tag/portfolio-handoff-2026-10-22). У релізі завантажте `download_and_restore.py` і запустіть `python download_and_restore.py`. Скрипт завантажить частини архівів, перевірить SHA-256 і розпакує всі матеріали в папку `originals/`. Це окремі матеріали для майбутньої роботи; для запуску сайту вони не потрібні.

GitHub Pages ще не налаштований. Сайт можна опублікувати з гілки `main`, папки `/ (root)`. `.nojekyll` уже доданий. Шляхи до зображень відносні й підтримують розміщення у підпапці репозиторію.

Анімації враховують системне налаштування зменшеного руху. Галереї підтримують стрілки, клавіатуру та свайпи на сенсорному екрані.
