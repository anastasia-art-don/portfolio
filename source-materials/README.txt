Повні оригінали портфоліо: 95 файлів із сайт.zip та 16 окремих вкладень.
Архіви поділені на частини по 20 МіБ для завантаження у GitHub.
Після клонування всього репозиторію запустіть:
python source-materials/restore_originals.py
Скрипт збере ZIP, перевірить SHA-256 і розпакує фото, PDF, AI та відео в source-materials/originals.
Код готового сайту знаходиться у корені репозиторію. Ці оригінали не потрібні для роботи сайту.
